# 官方彩｜原站手機版互動原型

直接用瀏覽器開啟 `index.html` 即可使用，無需安裝依賴。也可在此資料夾執行 `npm start`，開啟 http://127.0.0.1:4173 。

## 復刻依據

- 原站 `/gfc/index_mobile.html` 橘色手機版，而非 `/new/` 藍色新版。
- 以 390 × 844 手機直式版面實際檢視。支援窄手機；桌面開啟仍維持最多 480px 手機畫幅。
- 保留原站簡體文案、橘色漸層頂欄、灰色玩法列、圓形選號、底部操作區與原站圖片素材。
- 預設進入「一分賽車」選號頁；點標題或左上返回进入彩種目錄。

## 可操作流程

彩種目錄 → 選擇彩種 → 切換玩法 → 選號／快捷全大小單雙／機選 → 倍數與元角分 → 直接投注或加入號碼籃 → 確認 → 查看投注記錄 → 模擬撤單。

包含收藏編輯、側邊選單、開獎結果、趨勢、記錄篩選、歷史報表、號碼籃刪除／清空、手工錄入、建立／停止模擬追號計畫、明暗皮膚。

頂欄標題右側新增歷史開獎展開 icon。紅框標示的開獎資訊列會固定保留；點擊後由該列下方浮出橘色漸層／白色卡片面板，覆蓋玩法區並呈現最近 7 期、期號、開獎時間、彩球與「走勢」入口；再次點擊頂欄 icon 或面板右上箭頭即可收起。面板採用本原型橘色主題重新設計，不直接貼用參考截圖，也不會覆蓋底部投注列。

選單底部「演示設定」可調整模擬餘額、封盤狀態。預設餘額 10,000 元；倒數 165 秒後封盤，可由演示設定恢復。

## 技術交接與界線

此版本是離線互動原型，沒有正式 API、登入憑證、原站 session、真實投注或金流。只有圖片素材取自參考站，其餘邏輯獨立實作。

已直接核對：賽車手機選號與多名次版型、時時彩五星直选版型、11選5前三直选版型、遊戲目錄、選單、投注記錄空態、原站提示框及封盤提示。

投注成功、非空記錄、號碼籃、追號、報表與撤單的資料流程為演示補完，尚非逐像素或逐條業務規則驗證。快3／3D部分玩法與獎金為演示設定；時時彩複雜子玩法尚未完整展開。棋牌、趣味性、胆拖等未核對玩法會明示未開放，不應視為已確認的正式需求。新版彩票、開獎官網保留入口說明，不導向正式服務。

計算已覆蓋賽車不重號排列、定位胆相加、數字直选乘積、組合、元角分。正式全玩法賠率、限紅、返點、追號扣款時機、撤單窗口及派獎需由產品規格／服務端契約補齊。原型不自動派獎、不自動執行追號。

記錄與餘額存在 localStorage 的 `ig-official-mobile-prototype-v1`，不同瀏覽器／網址互不共用。刪除此鍵可重置演示資料。

## 檔案

- `index.html`：入口
- `style.css`：手機樣式
- `model.js`：彩種、玩法設定與純計算
- `app.js`：畫面、互動與本機資料
- `assets/`：原站圖片與 SVG
- `tests.cjs`：注數與金額檢查，執行 `npm test`
- `server.cjs`：僅綁定本機的靜態預覽服務

## 驗收重點

1. 390px、窄手機沒有橫向溢出，底部投注列固定且不遮住最後一列。
2. 冠亞各選 1、2 時為 2 注，不應包含 1/1 或 2/2。
3. 冠軍選 2 個、3 倍、角模式，總額 1.20 元。
4. 無號碼、必選位置缺漏、封盤、餘額不足均不得建立注單。
5. 取消確認不扣款；確認只新增一次記錄；撤單只退回一次。
6. 籃中方案保留各自彩種、號碼、倍數及單位；清除前有確認。
7. 重新整理後演示記錄保留；任何操作皆不向正式站點發送請求。
