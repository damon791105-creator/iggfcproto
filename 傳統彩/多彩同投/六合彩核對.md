# 原站手機版六合彩玩法核對

核對來源：使用者提供的 `ssc1.hbglsd2.site/ctc/htmls/mobile/index.html` 手機版「极速六合」頁面。核對時直接切換原站的主玩法與子玩法，查看畫面中的注區、號碼和選號方式；以下內容供多彩同投原型校正。賠率及生肖對應號碼可能隨期號更新，原型展示值不作為即時投注資料。

| 原站主玩法 | 子玩法／注區 | 可選內容與選號方式 |
| --- | --- | --- |
| 特码 | 特码 A、特码 B；特码两面 | A/B 各 1–49；兩面含大、小、單、雙、合單、合雙、尾大、尾小、紅／藍／綠波 |
| 正码 | 正码 A、正码 B；正码总和 | A/B 各 1–49；總大、總小、總單、總雙 |
| 正码特 | 正 1 特至正 6 特；正码特两面 | 各 1–49；兩面同特码兩面 |
| 连码 | 二全中、二中特、特串、三中二、三全中 | 各 1–49；二全中、二中特、特串都有複式、拖頭、生肖／尾數／生尾／任意對碰六種方式；三中二、三全中只有複式與拖頭 |
| 过关 | 正码一至正码六 | 每位有單、雙、大、小、紅波、藍波、綠波；跨位組合 |
| 特肖 | 單一注區 | 十二生肖，每個生肖顯示其對應號碼 |
| 特码头尾 | 特码头；特码尾 | 0–4 頭；0–9 尾 |
| 五行 | 單一注區 | 金、木、水、火、土，各項顯示涵蓋號碼 |
| 半波 | 單一注區 | 紅／藍／綠各有單、雙、大、小，共 12 項；各項顯示涵蓋號碼 |
| 七码 | 七码单、七码双、七码大、七码小 | 每區 0–7，共 32 項 |
| 六肖 | 二肖、三肖、四肖、五肖、六肖 | 每盤十二生肖，顯示生肖對應號碼；馬只有 01、13、25、37，不含 49 |
| 一肖尾数 | 一肖、一肖不中、尾数、尾数不中 | 前兩盤十二生肖；後兩盤 0–9 尾 |

| 尾数连 | 二至四尾連［中］、二至四尾連［不中］ | 六個子盤；每盤 0–9 尾，複式／拖頭 |
| 不中 | 五不中至十不中 | 六個子盤；各 1–49，複式／拖頭 |
| 多选中一 | 五選中一至十選中一 | 六個子盤；各 1–49，複式／拖頭；僅五選中一顯示賠率 |
| 特平中 | 一粒任中至五粒任中 | 五個子盤；各 1–49；僅一粒任中、五粒任中顯示賠率 |

此版依使用者最新校正與手機原站再次核對二全中六種方式、六肖馬的代表號碼及生肖連馬的賠率。無賠率的子盤不顯示橫線佔位；正式賠率仍須由玩法服務即時下發。
