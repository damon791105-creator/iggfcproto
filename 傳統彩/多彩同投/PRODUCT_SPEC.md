# 多彩同投｜产品规格书

- 版本：1.3（2026-11-17）
- 产品范围：传统彩手机端
- 状态：交付开发讨论；原型是交互演示，实际投注规则与接口以正式服务端为准。

## 1. 目标与范围

会员在同一页面同时配置多个彩种、各自选择玩法和金额，核对汇总后一次提交。页面以手机操作为主，重点是快速进入某张彩种卡、切换次玩法、选投注项和查看待投注数量。

本功能名称暂定 **多彩同投**。它与原有的 **经典投注** 是两套入口；经典投注页顶部有明显的「多彩同投」切换按钮，多彩同投页顶部可切回经典投注。投注内容、彩种、期号和金额均按卡片独立管理，底部统一汇总。

## 2. 页面结构与视觉状态

1. **顶部**：返回、页面标题、经典投注／多彩同投模式切换、功能菜单。界面文案使用简体字。
2. **投注桌概览**：显示当前彩种数、已组成且仍可提交的注数及「添加彩种」。未组成一注、已封盘的项目不计入可投注注数。
3. **快速前往**：三排小卡；超出手机宽度时可以左右滑动，并显示「左右滑动」提示。小卡显示子类名称、中类和封盘倒数；若该卡有有效待投注，小卡右上角显示注数角标，并显示「待投注 X 注」。点击小卡直接滚动至对应彩种卡，不改变其他卡的显示状态。
4. **彩种卡**：九张默认卡片的当前玩法投注区同时可用，无须额外展开。卡片顶部为中类图标预留位、子类名称、期号、封盘倒数、更换彩种、重置选号和右上角移除按钮；下方为上期开奖、历史入口、主／次玩法、当前注区、已选和小计、每注金额。数字注区在手机上尽量使用每排 5 项；次玩法较多时改为两排横向滑动，避免长清单。不同中类使用相邻但可区分的暖橘色调。中类图标暂以同尺寸占位，视觉素材另案设计。
5. **底部固定栏**：实时显示**可提交**注数及金额；如有已封盘选择，另显示其注数。没有任何有效选择时按钮不可用；只有已封盘选择时仍可进入清单核对，但提交按钮不可用。
6. **返回顶部**：滚动超过约 360px 后，在右下角显示向上箭头；不遮挡底部确认栏，点击后返回页面顶部。

倒数进入 **最后 30 秒（含 30 秒，不含 0 秒）** 时，对应的快速前往小卡与彩种卡同步出现暖橘色呼吸光圈，卡片上缘亮线和倒数文字同步强调。动画不移动内容；系统启用「减少动态效果」时改为静态边框提示。

## 3. 彩种卡操作规则

| 操作 | 规则 |
| --- | --- |
| 添加彩种 | 从按中类分组的选择器加入子类；已在投注桌中的**相同子类**不可再选。可加入同一中类的其他子类。加入后生成独立卡片并滚动到该卡。 |
| 更换彩种 | 可选其他尚未加入的子类。当前卡有已选项目时，先展示将清除的项目数与金额并要求确认；取消则原卡及选项不变。确认后清空该卡所有玩法选项与内部次玩法状态，重置为新彩种。 |
| 重置选号 | 按钮与「更换彩种」并列；没有已选项目时不可用。点击后先确认，只清空该卡选项，保留卡片、当前彩种与当前玩法。 |
| 移除彩种 | 卡片右上角 `×`，点击后始终提示确认。确认后从投注桌与快速前往同时移除；已有选项也一并删除，汇总立即更新。之后仍可重新添加。 |
| 切换主玩法 | 切换当前显示的注区，**保留**该卡其他主玩法和次玩法的已选项目。切回时恢复选中状态。 |
| 切换次玩法 | 用可直接点选的方块切换；只显示当前次玩法的注区，其他次玩法的已选项目继续保留。 |
| 选号 | 点击投注项切换选中／取消，更新卡片有效注数、快速前往角标、底部汇总。不同位置、玩法及次玩法分别记录，不能因显示文字相同而串选。 |
| 每注金额 | 每卡独立。输入正数，输入框至少完整显示六位整数 `100000`；两侧 `−／＋` 每次调整 10，最低为 1。卡片小计与总金额实时更新。正式上限、精度及限红由后端规则提供。 |

### 3.2 开奖历史

每张彩种卡在上期开奖旁提供「开奖历史」入口。点击后以**覆盖式浮层**显示最近 10 期，不改变投注桌高度；清单在浮层内部滚动，点击关闭按钮或遮罩返回。按期号由新到旧排列，每行对齐显示期号、开奖时间和完整结果。浮层依手机宽度自适应，期号与时间须清楚可读；号码较多时在同一期内换行，不缩成难辨认的小球。结果沿用 3.1 的中类规则：六合彩为 6 正码＋特别号且号码按波色，PK10 按名次顺序，快3用骰子，PC蛋蛋显示三球及和值。这一信息结构已按提供的手机原站核对。不同子类的历史数据按子类 ID 独立获取，不能只按中类共用。缺漏、延迟开奖或接口失败时显示明确状态，不补造开奖结果。当前静态原型以「原型示意数据」标注演示号码；正式版须接入真实开奖接口。

## 5. 注数与金额

设卡片 `g` 的有效注数为 `N_g`，该卡每注金额为 `A_g`。卡片小计 `S_g = N_g × A_g`；全页注数 `N = ΣN_g`，全页金额 `S = ΣS_g`，金额显示两位小数。切换到其他玩法后，原玩法已形成的注数仍计入 `N_g`。只选了项目但尚未形成一注时，保留选择状态，注数与小计为 0。

组合计注规则：

- 单项投注：每个有效投注项为 1 注。
- 位置直选：各必选位置的选号个数相乘；缺少任一位置为 0 注。11选5 直选须排除同一注中重复号码。
- 任选、连码、组选等复式：从 `n` 个已选号中取 `k` 个，注数为 `C(n,k)`；`n < k` 时为 0。
- 拖头：头码数为 `h`、拖码数为 `l`、每注需 `k` 个时，`0 < h < k` 才计 `C(l,k-h)`；同一号码不能同时作为头码与拖码。
- 连码对碰：先将 A/B 类别映射到实际号码集合，再计算同时包含两侧号码的不重复组合；两侧任一为空则为 0。
- 过关：至少选两个正码位置；有效注数为各已选位置项目数的乘积。
- PC蛋蛋包三：恰好选满 3 个不同号码时为 1 注；不足 3 个为 0，不能再选第 4 个。

**原型与正式结算的界线**：页面展示的赔率、期号和倒数为演示数据；正式注数、赔率、限额、可售状态和金额必须由后端重新校验，不能仅信任前端汇总。

## 6. 确认投注与异常

点击底部「确认投注」后，先显示所有有效待投注卡片、**所选期号、具体已选项目、玩法、各卡注数和金额、盘口状态**。可提交和已封盘的彩种逐卡标示；底部仅合计可提交注数与金额。未凑成一注的组合选项须提示「不会提交」，不能悄悄算入金额。会员可以返回继续修改，或确认一次提交跨彩种批次。

### 6.1 封盘提醒与跨期

1. 某彩种当期倒数进入 **15 秒及以下、仍大于 0 秒**，且该卡有至少 1 注有效待投注时，弹出一次提醒，显示子类、期号、剩余秒数和待投注注数。没有有效注数不弹。若同时有多张卡满足条件，按投注桌顺序依次提醒；其他操作弹窗开启时不覆盖它。
2. 提醒提供「跳往彩种」「查看并送单」「稍后处理」：跳往会定位该卡；查看并送单先进入确认清单，由会员核对后再提交；稍后处理只关闭本期提醒，不清除选择。每张卡每期最多主动提醒一次。若提醒仍开着时封盘，弹窗立即改为「本期已封盘」，送单入口改为查看封盘项目，不能继续显示可送单提示。
3. 封盘时间一到，该期选择暂时保留并标为「已封盘／不可提交」，不得送往下一期。**新一期确认开盘时，自动清空上一期所有未提交选项**（包括未凑成一注的选号），重置该卡待投注数与金额；玩法和每注金额保留。若封盘提醒仍显示，自动关闭。正式版应使用服务端推送或轮询的期号、封盘时间与可售状态；倒数由服务端时间校准，应用切后台后恢复也须重新同步。

### 6.2 送单状态与安全校验

确认清单逐卡展示所选原期号、已选投注项、注数、金额与「可提交」或「已封盘 · 不可提交」。全数已封盘时提交按钮不可用；仅部分已封盘时只允许送出仍开盘项目，已封盘项目在该期封盘期间保留并提示状态，**下一期确认开盘后自动清空**。会员点击最终提交时再次查询／校验期号和封盘状态；若自打开清单后状态变化，必须刷新清单并请会员重新核对。任何时间点均不能以客户端倒数作为最终准入依据。

正式开发建议使用**一个批次请求**，每个投注明细携带彩种 ID、期号、主／次玩法 ID、完整位置和选项、每注金额及赔率版本；请求需有幂等键，防止连点或重试重复扣款。服务端按当前封盘时间、彩种状态、赔率和账户余额逐条校验，返回每项结果与最终金额。前端只清除已确认成功的项目，失败项目保留并显示原因。批次是否允许部分成功属于待确认业务决策，不能由原型提示框代替真实回执。

正式版倒数以服务端时间和期号为准；封盘后不可继续提交该期投注，已选内容应明确提示下一步。当前原型用示意期号与倒数模拟封盘和跨期，确认后仅显示「原型演示」提示，**没有真实投注、扣款或回执**。

## 8. 验收清单

1. 手机宽度 320px、375px、390px 下可操作，卡片金额输入 `100000` 不截字，底部确认栏不遮挡最后的投注项。
2. 默认九类各一张卡；已加入子类不可重复添加或更换为另一张卡中的相同子类。
3. 快速前往保持三排；超出宽度后可左右滑动，待投注注数在对应小卡右上角和说明行同步出现；点击后准确定位对应卡片，其他卡仍可直接投注。
4. 主／次玩法切换不丢失选号；更换彩种会清空该卡全部选项，且有确认。新一期确认开盘后自动清空上一期未提交选项。重置与移除分别确认，语义和结果不能混淆。
5. 各彩种上期开奖数量与特别号／骰子／和值形式正确；六合彩波色与代表号码一致，其余彩种不套用波色。
6. 单项、位置、复式、拖头、过关、包三按上述规则形成注数；未完成的组合显示已选项目但不进入待投金额。
7. 每卡小计、快速前往角标、顶部注数和底部总额在选号、取消、更换、重置、移除及修改金额后同步更新。
8. 倒数进入最后 30 秒时对应小卡与彩种卡同步呼吸提示；系统减少动态效果时无持续动画；到 0 秒不再显示临近封盘呼吸状态。
9. 每卡可打开／关闭最近 10 期开奖浮层；列表在浮层内滚动，不推动投注桌，期号、时间、结果列对齐。320px、375px、390px 手机宽度下，文字与号码可读、号码自动换行且无水平溢出。中类专属结果形式正确；无数据或延迟开奖不会出现虚构号码。
10. 有待投注且剩余 15 秒时每卡每期仅提醒一次；跳往、进入确认清单、取消均可操作。弹窗开启后刚好封盘，不能送出原期。
11. 确认层逐卡显示已选内容及开盘状态；全关盘禁止提交，部分关盘只提交开盘项目。下一期确认开盘后，原期所有未提交选号自动清空，提醒和清单同步刷新或关闭，不再出现原期锁定提示。送单前服务端复核并防重复提交，关闭／赔率变更／余额不足时显示明确结果。
12. 经典投注与多彩同投双向入口可达，界面文案使用简体字。
13. 连码二全中、二中特、特串各有六种选号方式；六肖马不显示 49；生肖连「中」盘马使用独立赔率；多选中一与特平中只在有赔率的子盘显示数值，不以横线代替。

## 9. 上线前需确认

- 各彩种实时赔率、限红、单注／单期金额上限、金额小数精度及余额扣款规则。
- 批次投注是否允许部分成功；若允许，失败项保留与成功项清理的具体回执流程。
- 正式版收到期号／可售状态更新时的推送与轮询优先级、断网重连后的状态同步，以及跨期清空提示的展示时机。
- 投注桌草稿是否需跨刷新／跨设备保存，以及登录前后状态的归属。
- 各中类正式图标素材及视觉验收；目前为固定尺寸占位。
- 原站快照中部分复杂玩法的赔率或选项可能随期号变化，需与正式玩法服务再次核对。
