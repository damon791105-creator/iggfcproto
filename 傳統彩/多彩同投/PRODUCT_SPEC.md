# 多彩同投｜产品规格书

- 版本：1.0（2026-11-17）
- 产品范围：传统彩手机端
- 状态：交付开发讨论；原型是交互演示，实际投注规则与接口以正式服务端为准。

## 1. 目标与范围

会员在同一页面同时配置多个彩种、各自选择玩法和金额，核对汇总后一次提交。页面以手机操作为主，重点是快速进入某张彩种卡、切换次玩法、选投注项和查看待投注数量。

本功能名称暂定 **多彩同投**。它与原有的 **经典投注** 是两套入口；经典投注页顶部有明显的「多彩同投」切换按钮，多彩同投页顶部可切回经典投注。投注内容、彩种、期号和金额均按卡片独立管理，底部统一汇总。

## 2. 页面结构与视觉状态

1. **顶部**：返回、页面标题、经典投注／多彩同投模式切换、功能菜单。界面文案使用简体字。
2. **投注桌概览**：显示当前彩种数、已组成的待投注注数及「添加彩种」。未组成一注的选项不计入待投注注数。
3. **快速前往**：三排小卡；超出手机宽度时可以左右滑动，并显示「左右滑动」提示。小卡显示子类名称、中类和封盘倒数；若该卡有有效待投注，小卡右上角显示注数角标，并显示「待投注 X 注」。点击小卡滚动至对应彩种卡。
4. **彩种卡**：顶部为中类图标预留位、子类名称、期号、封盘倒数、更换彩种、重置选号、右上角移除按钮；下方为上期开奖、主玩法、次玩法、当前注区、已选和小计、每注金额。不同中类使用相邻但可区分的暖橘色调。中类图标暂以同尺寸占位，视觉素材另案设计。
5. **底部固定栏**：实时显示总注数、总金额和「确认投注」。没有有效投注时按钮不可用。
6. **返回顶部**：滚动超过约 360px 后，在右下角显示向上箭头；不遮挡底部确认栏，点击后返回页面顶部。

倒数进入 **最后 30 秒（含 30 秒，不含 0 秒）** 时，对应的快速前往小卡与彩种卡同步出现暖橘色呼吸光圈，卡片上缘亮线和倒数文字同步强调。动画不移动内容；系统启用「减少动态效果」时改为静态边框提示。

## 3. 彩种卡操作规则

| 操作 | 规则 |
| --- | --- |
| 添加彩种 | 从按中类分组的选择器加入子类；已在投注桌中的**相同子类**不可再选。可加入同一中类的其他子类。加入后生成独立卡片并滚动到该卡。 |
| 更换彩种 | 可选其他尚未加入的子类。当前卡有已选项目时，先展示将清除的项目数与金额并要求确认；取消则原卡及选项不变。确认后清空该卡所有玩法选项与内部次玩法状态，重置为新彩种。 |
| 重置选号 | 按钮与「更换彩种」并列；没有已选项目时不可用。点击后先确认，只清空该卡选项，保留卡片、当前彩种与当前玩法。 |
| 移除彩种 | 卡片右上角 `×`，点击后始终提示确认。确认后从投注桌与快速前往同时移除；已有选项也一并删除，汇总立即更新。之后仍可重新添加。 |
| 切换主玩法 | 切换当前显示的注区，**保留**该卡其他主玩法和次玩法的已选项目。切回时恢复选中状态。 |
| 切换次玩法 | 用可直接点选的方块切换；只显示当前次玩法的注区，其他次玩法的已选项目继续保留。 |
| 选号 | 点击投注项切换选中／取消，更新卡片有效注数、快速前往角标、底部汇总。不同位置、玩法及次玩法分别记录，不能因显示文字相同而串选。 |
| 每注金额 | 每卡独立。输入正数，输入框至少完整显示六位整数 `100000`；两侧 `−／＋` 每次调整 10，最低为 1。卡片小计与总金额实时更新。正式上限、精度及限红由后端规则提供。 |

## 5. 注数与金额

设卡片 `g` 的有效注数为 `N_g`，该卡每注金额为 `A_g`。卡片小计 `S_g = N_g × A_g`；全页注数 `N = ΣN_g`，全页金额 `S = ΣS_g`，金额显示两位小数。切换到其他玩法后，原玩法已形成的注数仍计入 `N_g`。只选了项目但尚未形成一注时，保留选择状态，注数与小计为 0。

组合计注规则：

- 单项投注：每个有效投注项为 1 注。
- 位置直选：各必选位置的选号个数相乘；缺少任一位置为 0 注。11选5 直选须排除同一注中重复号码。
- 任选、连码、组选等复式：从 `n` 个已选号中取 `k` 个，注数为 `C(n,k)`；`n < k` 时为 0。
- 拖头：头码数为 `h`、拖码数为 `l`、每注需 `k` 个时，`0 < h < k` 才计 `C(l,k-h)`；同一号码不能同时作为头码与拖码。
- 连码对碰：先将 A/B 类别映射到实际号码集合，再计算同时包含两侧号码的不重复组合；两侧任一为空则为 0。
- 过关：至少选两个正码位置；有效注数为各已选位置项目数的乘积。
- PC蛋蛋包三：恰好选满 3 个不同号码时为 1 注；不足 3 个为 0，不能再选第 4 个。

**原型与正式结算的界线**：页面展示的赔率、期号和倒数为演示数据；正式注数、赔率、限额、可售状态和金额必须由后端重新校验，不能仅信任前端汇总。

## 6. 确认投注与异常

点击底部「确认投注」后，先显示所有有效待投注卡片、期号、玩法、各卡注数和金额、总注数和总金额。未凑成一注的组合选项须提示「不会提交」，不能悄悄算入金额。会员可以返回继续修改，或确认一次提交跨彩种批次。

正式开发建议使用**一个批次请求**，每个投注明细携带彩种 ID、期号、主／次玩法 ID、完整位置和选项、每注金额及赔率版本；请求需有幂等键，防止连点或重试重复扣款。服务端按当前封盘时间、彩种状态、赔率和账户余额逐条校验，返回每项结果与最终金额。前端只清除已确认成功的项目，失败项目保留并显示原因。批次是否允许部分成功属于待确认业务决策，不能由原型提示框代替真实回执。

正式版倒数以服务端时间和期号为准；封盘后不可继续提交该期投注，已选内容应明确提示下一步。当前原型倒数会循环重置，确认后仅显示「原型演示」提示，**没有真实投注、扣款或回执**。

## 7. 接口与数据约定（待技术确认）

| 数据／接口 | 最低要求 |
| --- | --- |
| 彩种目录 | 中类、子类、唯一 ID、上下架状态、显示名称、图标 URL、排序 |
| 期号与时间 | 当前期号、封盘时间、服务端时间、可投注状态；切换彩种后重新获取 |
| 上期开奖 | 彩种 ID、上期期号、按该彩种规则排序的号码、特别号或和值信息 |
| 玩法目录 | 主／次玩法 ID、注区、选项、位置、赔率、组合所需个数、可售状态、版本号 |
| 批次投注 | 请求幂等键及多条明细；响应逐项结果、订单号、实际赔率／金额、失败原因 |

前端使用稳定 ID 存储选择状态，不以中文显示文案作为接口主键。倒数、赔率或可售状态变化后，确认层必须用最新服务端数据重新核对。具体接口路径与返回格式由前后端联调确定。

## 8. 验收清单

1. 手机宽度 320px、375px、390px 下可操作，卡片金额输入 `100000` 不截字，底部确认栏不遮挡最后的投注项。
2. 默认九类各一张卡；已加入子类不可重复添加或更换为另一张卡中的相同子类。
3. 快速前往保持三排；超出宽度后可左右滑动，待投注注数在对应小卡右上角和说明行同步出现；点击后准确定位卡片。
4. 主／次玩法切换不丢失选号；更换彩种才清空该卡全部选项，且有确认。重置与移除分别确认，语义和结果不能混淆。
5. 各彩种上期开奖数量与特别号／骰子／和值形式正确；六合彩波色与代表号码一致，其余彩种不套用波色。
6. 单项、位置、复式、拖头、过关、包三按上述规则形成注数；未完成的组合显示已选项目但不进入待投金额。
7. 每卡小计、快速前往角标、顶部注数和底部总额在选号、取消、更换、重置、移除及修改金额后同步更新。
8. 倒数进入最后 30 秒时对应小卡与彩种卡同步呼吸提示；系统减少动态效果时无持续动画；到 0 秒不再显示临近封盘呼吸状态。
9. 确认层可一次核对多个彩种；提交前服务端复核并防重复提交，关闭／赔率变更／余额不足时显示明确结果。
10. 经典投注与多彩同投双向入口可达，界面文案使用简体字。

## 9. 上线前需确认

- 各彩种实时赔率、限红、单注／单期金额上限、金额小数精度及余额扣款规则。
- 批次投注是否允许部分成功；若允许，失败项保留与成功项清理的具体回执流程。
- 封盘或跨期时已选项目的处理、期号更新后是否允许一键转投下一期。
- 投注桌草稿是否需跨刷新／跨设备保存，以及登录前后状态的归属。
- 各中类正式图标素材及视觉验收；目前为固定尺寸占位。
- 原站快照中部分复杂玩法的赔率或选项可能随期号变化，需与正式玩法服务再次核对。
