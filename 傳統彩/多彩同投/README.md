# 多彩同投｜手機版設計原型

這份設計草稿以九大彩種分類各放一款代表彩種：六合彩、PK10、时时彩、快乐十分、11选5、快乐8、快3、3D、PC蛋蛋。每張卡片都可獨立選玩法、投注項目和金額，頁面底部彙總所有卡片的投注。

在傳統彩本機預覽服務啟動時，可開啟 `http://127.0.0.1:4174/多彩同投/index.html` 預覽。

正式開發交接請閱讀 [多彩同投產品規格書](PRODUCT_SPEC.md)，其中包含畫面、操作、計注、接口需求與驗收條件。

## 可互動流程

- 點選投注項、調整每項金額，卡片小計與整頁總計即時更新。
- 每張彩種卡片只顯示當前次玩法的投注區；所有次玩法都以可直接點選的方塊切換。各次玩法的選號獨立記錄，切回原盤仍保留已選項目。
- 切換同一彩種的玩法會保留各玩法已選投注項，切回後可繼續編輯；卡片小計及確認投注會匯總所有玩法。更換彩種時才會提示並清空該卡片投注內容。
- 六合彩依原站手機版整理為 17 個主玩法。子盤口的選項與顯示賠率會隨切換更新；五行、半波與生肖項目直接標示涵蓋號碼。詳見 [六合彩核對.md](六合彩核對.md)。
- 六合彩「连码」中，二中特與特串提供「复式、拖头、生肖对碰、尾数对碰、生尾对碰、任意对碰」六種方式；二全中、三中二、三全中只提供「复式、拖头」。二碼、三碼依組合數計注；拖頭分別選頭碼與拖碼，對碰分 A／B 區。未湊足一注時不計入投注總額。
- 生肖連、尾數連、不中、多選中一、特平中的複選依子玩法所需個數組合計注；過關需至少選兩個正碼位置才形成一注。
- PK10 只保留「正確號碼」與「兩面盤」兩個主玩法：正確號碼下可切換冠亞和（3–19）及冠軍至第十名（1–10）；兩面盤下可切換冠／亞軍和及十個名次，各次玩法只顯示對應的大小、單雙或龍虎。不同次玩法的投注分開記錄並一併匯總。
- 时时彩以原站手機版注區重整為七個主玩法：兩面盤、正確號碼、前中后、组合/定位、组选、跨度、和数。「组合/定位」下可直接切換一字组合、二字组合、三字组合、二字定位、三字定位；「组选」下可切換组选三、组选六。各次玩法內保留原站的前三／中三／后三等範圍或位置組合切換。二字、三字定位依萬位、仟位、佰位等實際位置分排，各排顯示 0–9，選滿所需位置才計為投注。原站的第一至第五球號碼合併在「正確號碼」，各球兩面合併在「兩面盤」。
- 快乐十分的正碼與第一至第八球號碼歸入「正確號碼」，各球兩面歸入「兩面盤」，方位／中發白逐項列出代表號碼。任选二、任选三、任选四、任选五歸入「任选」的四個可直接切換的次玩法；选二连组與选三前组維持各自入口。11选5 的逐球號碼與兩面也分別歸類，直选按位置分成兩或三個直欄，選號與賠率隨前二／前三切換；相同號碼出現在不同位置不重複計成有效注。
- 快乐8 依手機原站保留兩類投注玩法：「兩面盤」有總和／總和過關、前後和、單雙和、五行四個次玩法；「正確號碼」收納原站的正碼 1–80。原站沒有「選一～選十」投注玩法。
- 快3 將「三军、大小」「全骰、围骰」「长牌」「短牌」「点数」直接列為主玩法，骰子投注項以大尺寸點數骰面呈現。3D 的三球號碼歸入「正確號碼」，各球兩面歸入「兩面盤」，上期開獎只顯示三個號碼；其餘整合、主勢盤、組合、定位、和數、組選注區及次玩法保留。PC 蛋蛋只保留原站的和值、兩面、色波／豹子、包三四個次玩法；包三直接顯示 00–27，最多選三個不同號碼，選滿才形成一注。
- 定位與複式類玩法按位置數量或組合數計注。未選齊時卡片會顯示已選項目與 0 注，跨彩種總額僅計入已形成的投注。
- 點「更換」選擇其他彩種；已有投注時，先確認是否清除。
- 每張卡片直接顯示「重置選號」與「移除彩種」：「重置選號」只清空該彩種投注項並保留卡片與玩法；「移除彩種」會從投注桌移除該卡片。兩者執行前都會再次確認。
- 點「添加彩种」加入其他彩種；已在頁面中的彩種會停用，避免重複加入。
- 點「確認投注」查看跨彩種彙總，再以原型提示模擬一次提交。
- 快速前往維持三排；手機上若彩種超出寬度可左右滑動，有待投注時於小卡右上顯示注數。
- 各彩種封盤倒數進入最後 30 秒時，快速前往小卡和主卡同步顯示呼吸光暈；偏好減少動態效果時顯示靜態提示。
- 每注金額可完整顯示六位整數，頁面滾動後可用右下角箭頭返回頂部。

中類圖片位置先以「圖片額外設計」佔位，保留固定大小，待後續另行設計圖示。上期開獎依彩種規則展示：六合彩為六個正碼加一個特別號、PK10 為十名、时时彩為五球、快乐十分為八碼、11选5 為五碼、快乐8 為二十碼、快3 為三顆骰子、3D 為百拾個三位、PC蛋蛋為三碼與和值。

目前只做介面演示；上期號碼、期號、循環倒數、賠率及提交結果皆為展示資料，不連接開獎、投注 API 或金流。

`reference-mobile-*.json` 記錄了從提供的手機原站畫面逐項核對的投注選項。六合彩延續獨立實作，其餘八個彩種執行 `node build-reference-data.cjs` 後會更新原型使用的 `reference-mobile-data.js`。賠率是該次檢視的畫面快照，非即時資料。

核對備註：原站「时时彩 → 组选六」畫面顯示 119 項，清單沒有 `678`；原型目前照該畫面保留 119 項，供後續與產品規則確認。
