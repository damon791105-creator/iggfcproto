# 傳統彩｜手機互動原型

這是獨立於「官方彩」的手機版彩種入口與投注原型。預設開啟彩種目錄，包含 PK10、時時彩、快樂十分、11選5、快樂8、快3、3D、PC蛋蛋與六合彩分類。

在此資料夾執行 `npm start` 後開啟 `http://127.0.0.1:4174/`。預設顯示手機版彩種大廳；投注頁可點選彩種進入，或直接開啟 `http://127.0.0.1:4174/#gamePage`。

目前為離線互動原型，開獎、倒數、賠率、餘額、注單及追號皆為模擬資料；不連接原站 API、帳號、投注或金流。資料使用獨立的 `ig-traditional-mobile-prototype-v1` localStorage key，與官方彩資料分離。

## 多彩同投

在經典投注頁頂部點「多彩同投」進入新版跨彩種投注桌，或直接開啟 [多彩同投原型](多彩同投/index.html)。九類彩種各有一張預設卡片，可切換玩法、選號、調整金額並一起核對投注。開發交接內容見 [產品規格書](多彩同投/PRODUCT_SPEC.md)。

## 結構

- `index.html`：傳統彩獨立入口
- `app.js`：手機介面、互動與本機演示狀態
- `model.js`：彩種、玩法與注數計算
- `style.css`：手機版樣式
- `assets/`：圖示素材
- `server.cjs`：本機預覽服務
